# 03 — Failure Mode Capture

Log every failure as it happens. A failure is any moment an agent: hallucinated an API/field, loaded the wrong/too many files, produced code that violated a standard, missed a gate step, or needed a human to correct course.

For each: what happened, which file/instruction caused or failed to prevent it, severity, and the proposed KB fix. Feed into `04-kb-update-workflow.md`.

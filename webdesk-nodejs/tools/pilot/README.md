# Pilot Workflow

How to run a controlled pilot of the WebDesk Node.js Delivery System and feed what breaks back into the knowledge base. The first pilot is **DDI System's Inform ERP ↔ Node middleware + dashboard ↔ BigCommerce**.

Run order: `01-pilot-selection` → `02-pilot-kickoff-checklist` → run the project through the gates → `03-failure-mode-capture` (continuously) → `04-kb-update-workflow` → `05-post-pilot-retro` → `06-pilot-success-metrics`.

The point of a pilot is not to ship perfectly — it is to discover where the system's instructions are wrong, thin, or missing, and fix them before the second project. Capture every failure mode honestly.

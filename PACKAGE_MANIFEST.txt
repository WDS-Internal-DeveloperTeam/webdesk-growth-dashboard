This manifest covers the FULL EXPORT PACKAGE, not just the project profile.
It exists because an earlier export nested docs/implementation/ and docs/skill-build/
inside the profile directory, which produced spurious validator failures unrelated
to the profile's actual correctness. This package instead places every top-level
piece at package root, matching docs/skill-build/project-skill-build-report.md's
package layout diagram.

The project profile itself has its own separate, narrower manifest scoped to only
its 51 files: skills/nodejs/projects/custom-app-build/profiles/webdesk-growth-dashboard/MANIFEST.txt
Do not duplicate that list here.

This package is deliberately LEAN: it does not bundle the full base Node.js skill
(webdesk-nodejs/skills/nodejs/_spine/, nodejs/knowledge/, _contracts/, tools/scripts/,
etc.) — only the project-specific profile subtree, this project's own reports, and
its canonical source inputs. Running the profile's own tools/validate-all.py from
inside this package therefore runs in STANDALONE mode (13/14 real checks + 1
explained, non-failing SKIP for the one check that genuinely needs the real base
schema) — this is expected, not a defect. Re-run the same script from inside a full
base-skill checkout for the full 14/14 result. See docs/skill-build/validation-report.md.
This packaging shape was confirmed with the project owner on 2026-08-06 after a
review assumed the full base skill was bundled; it is not.

Two validators ship with this package:
- skills/nodejs/projects/custom-app-build/profiles/webdesk-growth-dashboard/tools/validate-all.py
  — validates the PROFILE
- validate-package.py (this package's own root) — validates the PACKAGE as a whole
  (manifest accuracy, hygiene, canonical-input presence). Run both.

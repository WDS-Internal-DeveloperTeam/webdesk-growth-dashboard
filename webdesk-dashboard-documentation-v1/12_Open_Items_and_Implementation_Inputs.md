# Open Items and Implementation Inputs

The dashboard specification is complete enough for implementation. The following items are intentionally deferred to setup, technical discovery, or later data population.

## 1. Setup-time configuration

- final Vercel project IDs;
- exact PostgreSQL provider record shown through Vercel;
- database connection values;
- Upstash credentials;
- Vercel Blob store IDs;
- GitHub App ID and installation;
- repository URLs;
- WordPress integration credentials;
- SMTP host/user secret references;
- primary Google Workspace domain designation;
- actual operational owners and multiple notification emails;
- incident and escalation contact details.

## 2. WordPress implementation verification

- confirm reported WordPress/PHP versions;
- verify REST API and Application Passwords;
- verify WP-CLI and SSH constraints;
- audit current active theme;
- complete Theme Migration and Reconciliation Report;
- verify plugin activity and dependencies;
- verify GA4/GTM/Clarity IDs and consent;
- document Contact Form 7 to Podio mapping and failures;
- run core/plugin integrity checks;
- create Technical Debt Register.

## 3. Deferred integrations

- external malware-scanning provider;
- automatic Anthropic/Claude API execution;
- continuous GA4/GSC ingestion;
- public portal;
- billing;
- mobile app.

## 4. Data population that can happen during or after development

- complete service catalogue;
- all deliverables;
- complete platform/technology mapping;
- full keyword/entity research;
- page keyword map;
- internal linking inventory;
- proof and claims catalogue;
- case-study/portfolio mappings;
- content templates;
- search briefs;
- schema map.

The existing spreadsheet template can be used for staged import and testing.

## 5. Business review

The Growth Director should later review and recommend improvements to:

- Company Persona;
- Marketing Profile;
- ICPs;
- positioning;
- brand voice;
- messaging tracks;
- service priorities;
- proof strategy;
- website strategy.

Recommendations do not change approved business documents without human approval.
